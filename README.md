# Redisson Distributed Lock Demo

A demo project of how to implement a distributed lock using Redisson

## Prerequisites

* Maven
* Java 17
* Redis

## How to run this project
1. Clone this project on IntelliJ IDEA.
2. Start your local Redis server.
